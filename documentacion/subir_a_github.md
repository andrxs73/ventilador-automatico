# Subir el proyecto a GitHub desde Windows (sin Git instalado)

1. Entrar en https://github.com e iniciar sesión.
2. Pulsar **New repository** y escribir `ventilador-automatico-wifi`.
3. Elegir visibilidad según indique el docente; crear el repositorio.
4. Descomprimir `Entrega_Ventilador_WiFi.zip` en el computador.
5. Dentro del repositorio nuevo, pulsar **Add file → Upload files**.
6. Abrir la carpeta descomprimida, seleccionar los archivos y carpetas del proyecto y arrastrarlos al área de carga de GitHub. **Verificar que `README.md` quede en la raíz y que las carpetas `codigo`, `simulador`, `pruebas`, `diagramas`, `documentacion` y `evidencias` estén bien ubicadas.** Si el navegador no conserva la estructura de carpetas al subir, usar GitHub Desktop o subir los archivos por carpetas.
7. Pulsar **Commit changes** y esperar.
8. Abrir el README en GitHub; comprobar que sus enlaces funcionen. Copiar la URL del repositorio para la entrega.
9. Antes de entregar: reemplazar nombres entre corchetes, ejecutar pruebas S1–S5, añadir capturas reales y el enlace al video grabado.

**No subir:** contraseñas Wi-Fi personales, claves, tokens o datos privados. **No presentar la simulación como prototipo físico validado.**
